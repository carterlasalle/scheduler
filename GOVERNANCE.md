# Governance

This project is governed by the Coding Hermes project maintainers.

## Decision Making

Architectural decisions are documented in `docs/adr/` using Architecture Decision Records (ADRs).

## Code of Conduct

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Maintainer Responsibilities

- Review and merge pull requests
- Respond to issues within a reasonable timeframe
- Ensure CI/CD pipelines remain functional
- Maintain backward compatibility where possible
- Document significant changes in [CHANGELOG.md](CHANGELOG.md)

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for development guidelines and the contribution process.
